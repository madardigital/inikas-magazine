# انعكاس | ما خلف المرآة

ملفات الموقع الكاملة، بأحدث تعديلات شريط التنقل والفريق دون أرقام.

## التشغيل
افتح `index.html` مع إبقاء مجلدي `assets` و`content` بجانبه. لا حاجة لتثبيت حزم أو تنفيذ بناء.

## GitHub Pages
من Settings ثم Pages اختر Deploy from a branch، والفرع `main` والمجلد `/(root)` ثم Save.

## الملفات
- `assets/css/style.css`: التصميم والتجاوب.
- `assets/css/fonts.css`: تعريف الخطوط المحلية.
- `assets/fonts`: خطا El Messiri وIBM Plex Sans Arabic وملفا الترخيص.
- `assets/js/app.js`: التنقل والبحث والتفاعلات.
- `content/articles.js` و`content/articles2.js`: محتوى المواد المعتمد.
- `assets/images`: الصور والشعار الأصليان.

تظهر قائمة الأقسام الأفقية من عرض 900 بكسل، بما يشمل عرض 980 بكسل الشائع في وضع سطح المكتب على الهاتف. العرض الأصغر يحتفظ بالقائمة الجانبية. لا تُحمَّل الخطوط من Google Fonts.
